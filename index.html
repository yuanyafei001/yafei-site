安全教育培训 AI Agent 系统

2026.02 – 2026.07

5个 Agent 协作
3周→3天新工地部署周期
0规范条文编造（幻觉抑制）

公司承接多个工地安全管控项目，传统方式每个工地都要独立部署 RAG 知识库、配置大模型、搭建业务流程， 重复建设严重、难以规模化。同时安全交底涉及规范条文引用，大模型"幻觉"存在合规风险。

工作内容

  • 负责 1 个主 Agent + 4 个安全 Agent（语音交互与内容结构化、交底培训、风险辨识、整改审核）的协作流程设计与状态机编排。
  • 设计并实现 MCP 协议工具网关，统一封装知识库检索、风险校验、文档生成等能力，工具层与 Agent 逻辑解耦。
  • 搭建安全规范、交底模板、危险源台账三大向量库，完成 BGE-M3 检索链路与 CoT 校验逻辑。
  • 设计租户隔离方案与三层容错机制（重试 / 模块降级 / 系统兜底），保障多项目并行稳定。

核心亮点

  • 可复用 Agent 模板沉淀：基于 LangGraph 搭建 5 个 Agent 协作引擎，配置化适配不同工地的安全规范与风险台账，新工地部署周期从 3 周缩短至 3 天。
  • MCP 标准化工具网关：统一封装检索 / 校验 / 文档生成与导出，定义标准化 JSON Schema 调用规范，新增工具无需修改 Agent 核心代码。
  • 合规校验与幻觉抑制：BGE-M3 混合检索 + Reranker 精排提升召回精度；CoT 思维链对交底条文抽样校验并附带规范溯源，低置信度风险项自动增加免责提示，解决"编造规范条文"的合规风险。
  • 高可用与多租户隔离：三层容错 + 租户 ID / 向量库命名空间实现项目级数据隔离，支撑多项目并行管控。
  • 工程决策：隐患照片涉及现场数据安全合规，无法上传公网 API —— 选型 Qwen-VL 本地私有化部署，推理成本约为 GPT-4V 的 1/10，在精度可接受前提下优先保障数据安全与成本可控。

✅ 成果：安全管控全流程线上化闭环；沉淀标准化 Agent 模板，可快速迁移至矿山、电力等安全场景。

智能物资验收与票据识别系统

2025.07 – 2025.12

工地物资票据格式多样（电子 PDF / 热敏纸小票 / 手机拍照），传统单厂商 OCR 换格式就得换方案； 通用 OCR 对模糊、倾斜、反光的拍照票据识别率极低。

  • 责任链模式解析调度器：PyMuPDF（电子 PDF）→ PaddleOCR-VL（打印小票）→ Qwen-VL（模糊拍照票据）依次尝试，低置信度自动流转，核心字段提取覆盖率 95%+（1 万+ 标注测试集）。
  • 低质量票据优化：布局分析自适应裁切 + 多角度融合识别，倾斜/低质量票据召回率 72% → 89%。
  • 溯源定位机制：回答自动附带票据截图坐标引用（page_num, x1, y1, x2, y2），支持点击溯源核对。

✅ 成果：人工录单量显著降低，计量准确性大幅提升；方案已规划迁移至物流、仓储场景。
